# AnixOps SD-WAN 1.0.0 使用教程

这版发布提供了 Linux `amd64` 的二进制资产和发布清单：

- `anix-agent-linux-amd64`
- `anix-control-linux-amd64`
- `anix-node-linux-amd64`
- `anix-release-linux-amd64`
- `anix-ui-linux-amd64`
- `anixops-sd-wan_1.0.0_linux_amd64.tar.gz`
- `SHA256SUMS`
- `release.json`

GitHub Release:
https://github.com/AnixOps/AnixOps-sd-wan/releases/tag/v1.0.0

## 1. 下载与校验

```sh
curl -LO https://github.com/AnixOps/AnixOps-sd-wan/releases/download/v1.0.0/anixops-sd-wan_1.0.0_linux_amd64.tar.gz
curl -LO https://github.com/AnixOps/AnixOps-sd-wan/releases/download/v1.0.0/SHA256SUMS
curl -LO https://github.com/AnixOps/AnixOps-sd-wan/releases/download/v1.0.0/release.json
sha256sum -c SHA256SUMS
tar -xzf anixops-sd-wan_1.0.0_linux_amd64.tar.gz
```

`SHA256SUMS` 覆盖了本次 Linux `amd64` 资产；`release.json` 是发布清单，包含产物哈希、版本号和回滚信息。

## 2. 先看版本

```sh
./anix-agent --version
./anix-control --version
./anix-node --version
./anix-release version
```

桌面端需要 `fyne` 运行环境，发布包里已经带了可执行文件：

```sh
./anix-ui --agent-url http://127.0.0.1:18080
```

## 3. 本地最小演示

先起控制面，再起本地 Agent API。

终端 1：

```sh
./anix-control --addr 127.0.0.1:8080
```

终端 2：

```sh
./anix-agent --local-api-addr 127.0.0.1:18080
```

然后可以直接查看本机状态：

```sh
curl http://127.0.0.1:18080/healthz
curl http://127.0.0.1:18080/v1/snapshot
curl http://127.0.0.1:18080/v1/telemetry
curl http://127.0.0.1:18080/v1/config
curl http://127.0.0.1:8080/healthz
curl http://127.0.0.1:8080/version
```

`/v1/config` 支持读取和提交本机配置。比如把 `transport` 改掉：

```sh
curl -X POST http://127.0.0.1:18080/v1/config \
  -H 'Content-Type: application/json' \
  -d '{"id":"local","tenant_id":"default","target_id":"local-dev","version":"v1","values":{"transport":"hysteria2"}}'
```

## 4. 桌面 UI

如果机器上有 GUI 环境，可以直接打开桌面程序：

```sh
./anix-ui --agent-url http://127.0.0.1:18080
```

UI 里可直接操作：

- `Settings`：读取和提交本机配置
- `Protocol switching`：切换当前 transport
- `Diagnostics`：运行本地自检
- 系统托盘菜单：显示窗口、自检、开机自启

## 5. 如果你只想做发布检查

`anix-release` 可以验证发布清单：

```sh
./anix-release verify --base-dir . --manifest release.json
```

也可以查看回滚计划：

```sh
./anix-release rollback-plan --manifest release.json
```
