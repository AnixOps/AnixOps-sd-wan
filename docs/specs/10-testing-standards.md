# 10. 测试标准

> 状态：草案锁定  
> 规则：没有通过规定测试矩阵，不进入正式版。

## 1. 测试层级
- 单元测试
- 集成测试
- 协议互通测试
- 跨平台兼容测试
- 端到端测试
- 容错与故障切换测试
- 安全测试
- 回归测试

## 2. 必测矩阵
### 2.1 平台
- Linux
- Windows
- macOS

### 2.2 架构
- x86_64
- ARM64

### 2.3 协议
- Native WireGuard
- Hysteria2
- REALITY
- TUIC

### 2.4 场景
- 专线
- 公网跨境
- 移动网络
- 高 QoS
- 高抖动
- UDP 不可用
- 节点故障
- 出口切换
- 多租户隔离

## 3. 必测内容
- 客户端启动、停止、重连。
- 配置下发与回收。
- 证书签发、轮转与吊销。
- 入口切换与回退。
- 海外 Core 故障切换。
- 出口策略命中。
- 控制面权限校验。
- UI 基础操作与状态刷新。

## 4. 验收标准
- 首版必须在规定平台上可用。
- 核心链路必须可恢复。
- 策略变更必须可追踪。
- 节点级故障切换必须可重复验证。
- 多租户隔离必须通过验证。

## 5. 回归要求
- 协议修改必须触发协议测试回归。
- 策略修改必须触发路由与出口测试回归。
- UI 修改必须触发桌面基本流程回归。
- 控制面修改必须触发权限与审计回归。

## 6. 证据要求
- 必须保留测试记录。
- 必须保留关键日志和状态快照。
- 必须保留可复核的失败样本。
