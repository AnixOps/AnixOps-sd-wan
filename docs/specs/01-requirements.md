# 01. 需求定义

> 状态：草案锁定  
> 规则：本文件中的已确认条目不得随意修改；新增或未确认内容进入 `12-open-questions.md`。

## 1. 产品定义
- 产品类型：企业级跨境 SD-WAN 平台。
- 最终形态：客户端 Agent + 桌面 UI + 中国边界入口层 + 海外边界层 + 海外 SD-WAN Core + 多出口层。
- 目标能力：多入口、多出口、抗封锁、智能选路、全球 Overlay、专线融合、自动切换。

## 2. 适用场景
- 企业跨境
- 海外加速
- 多云互联
- 专线融合
- 多运营商接入
- 多地区出口
- AI 与国际业务网络

## 3. 首版范围
- Go 语言实现。
- 客户端优先覆盖 Linux、Windows、macOS。
- 保留手机端适配可能性，但首版不做完整移动端产品。
- 客户端采用“常驻 Agent + 桌面 UI”形态。
- 桌面 UI 采用 Go + Fyne，不采用 HTML 套壳。
- 控制面自研，提供 Web 控制台与 API。
- 支持多租户。
- 支持协议自动切换。
- 支持节点级故障切换。
- 支持日志和监控上报海外控制面。

## 4. 功能需求
### 4.1 接入与传输
- 支持 Native WireGuard。
- 支持 Hysteria2。
- 支持 REALITY。
- 支持 TUIC。
- 支持按链路状态自动选择传输方式。
- 支持按专线、公网、QoS、UDP 可用性进行判断。

### 4.2 本地网络能力
- 支持 LAN 接入。
- 支持 DHCP。
- 支持 DNS。
- 支持透明代理。
- 支持策略路由。
- 支持链路探测与自动切换。
- 支持配置下发。
- 支持日志与监控。

### 4.3 海外边界与核心
- 支持海外边界节点接收、鉴权、限速、入口调度。
- 支持海外 SD-WAN Core 仅使用纯 WireGuard 作为 Overlay。
- 支持 FRR + BGP 做动态选路、ECMP 与故障切换。
- 支持多区域出口池化。

### 4.4 出口策略
- 支持按域名、IP、ASN 组合做出口选择。
- 支持 AI、视频、企业业务、国内回源等策略分类。
- 支持出口节点可插拔，不锁死固定区域配比。

### 4.5 管理与运维
- 支持 Web 控制台。
- 支持 API。
- 支持多租户、权限与审计。
- 支持证书生命周期管理。
- 支持控制面向客户端与边界节点下发配置。

## 5. 非功能需求
- 跨平台可用性优先。
- 传输层与 Overlay 必须分离。
- 海外 Core 不叠加 REALITY 之类的入口伪装协议。
- 监控与日志上报路径必须可控。
- 正式版前所有决策均可追溯。

## 6. 验收标准
- 三类入口可以被识别、切换与回退。
- 客户端可以在 Linux、Windows、macOS 上启动并连接控制面。
- 海外 Core 可以稳定形成 WireGuard Overlay。
- FRR + BGP 可以完成动态路由与故障切换。
- 出口策略可以按规则稳定命中。
- 控制面可以管理多租户对象、设备与策略。
