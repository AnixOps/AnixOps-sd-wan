# 02. 架构定义

> 状态：草案锁定  
> 规则：本文件描述已确认架构边界；未决项进入 `12-open-questions.md`。

## 1. 总体分层
```text
[客户端接入层]
        ↓
[中国边界传输层]
        ↓
[海外边界层]
        ↓
[海外 SD-WAN Core]
        ↓
[多出口层]
```

## 2. 角色边界
### 2.1 客户端接入层
- 运行位置：客户机房、企业出口、软路由、旁路由、Mini PC、x86 设备。
- 运行形态：常驻 Agent + 桌面 UI。
- 主要职责：LAN 接入、DHCP、DNS、透明代理、策略路由、链路探测、自动切换、配置下发、日志、监控。

### 2.2 中国边界传输层
- 负责中国侧与海外边界之间的抗封锁传输。
- 负责入口协议接入与切换。
- 负责把流量转入海外边界节点。
- 不承担海外核心 Overlay 职责。

### 2.3 海外边界层
- 负责接收中国流量，也负责接收海外普通节点的外层接入流量。
- 负责鉴权、限速与入口调度。
- 对大陆专线直达的海外节点，外层可以直接使用 WireGuard。
- 对海外非大陆专线节点，外层接入统一采用 WireGuard over REALITY。
- 负责把流量接入海外 SD-WAN Core。

### 2.4 海外 SD-WAN Core
- 负责节点互联、动态选路、故障切换、多出口与智能路由。
- Overlay 仅使用纯 WireGuard。
- 动态路由使用 FRR + BGP。
- 不再继续套用 REALITY 等入口伪装协议。

### 2.5 多出口层
- 负责把业务流量导向不同区域出口。
- 负责维护出口池与策略映射。
- 负责给上层提供可插拔、可扩展的出口节点集合。

### 2.6 香港节点
- 香港按普通海外节点处理，不单独作为中国侧专用边界定义。
- 香港节点可根据角色进入海外边界层、海外 Core 或多出口层。
- 若香港节点属于大陆专线接入，则其外层接入可直接使用 WireGuard。
- 若香港节点不属于大陆专线接入，则其外层接入遵循 WireGuard over REALITY。

## 3. 控制面位置
- 控制面为自研系统。
- 控制面不在用户数据路径中。
- 控制面负责身份、配置、证书、策略、审计与监控汇聚。

## 4. 推荐部署区域
- 香港
- 日本
- 新加坡
- 美国西海岸
- 德国

## 5. 核心拓扑原则
- 传输层与 Overlay 分离。
- 大陆专线节点可直接以 WireGuard 进入海外节点。
- 海外非大陆专线节点的外层接入使用 WireGuard over REALITY。
- 海外核心只做 WireGuard Mesh。
- 入口与出口解耦。
- 控制面与数据面解耦。
- 节点级故障切换是首版高可用底线。

## 6. 架构摘要
```text
Client Agent / Desktop UI
    -> China Transport Entry
    -> Overseas Edge POP
    -> WireGuard Core + FRR/BGP
    -> Egress Pool
    -> Target Service
```
