# Implementation Coverage

> Status: active implementation tracking.

This matrix maps the locked product requirements to concrete code artifacts and verification evidence. It is intentionally strict: an interface, placeholder, or passing unrelated test is not counted as a complete implementation.

## Legend
- Complete: implemented and covered by direct tests or runnable verification.
- Partial: meaningful code exists, but the requirement is not fully implemented or not fully verified.
- Not started: no implementation evidence exists.
- External/system: requires real network, platform, package, or deployment validation beyond local unit tests.
